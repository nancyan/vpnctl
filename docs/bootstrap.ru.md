# Подготовка нового VPS (экспериментальная v0.3)

**Только для отдельного тестового VPS на Ubuntu/Debian, где нет 3x-ui и Xray.** Никаких изменений в рабочей цепочке VPN. Версия 0.3 устанавливает NGINX со стандартными настройками ОС; опционально — самостоятельный Xray из релиза с проверяемым SHA-256 и заранее подготовленным ПРИВАТНЫМ JSON. Настройки VLESS/REALITY автоматически пока не генерируются.

1. Создайте отдельный тестовый VPS, независимо проверьте IP и SSH host key.
2. На ТЕСТОВОМ VPS вручную выполните `sudo touch /etc/vpnctl-allow-bootstrap`.
3. Скопируйте `inventory/hosts.yml` в исключённый из Git файл `inventory/local.yml`; добавьте **новый** узел `test_vps`, установите `vpnctl_fresh_host: true`. Никогда не применяйте этот флаг к боевым серверам.
4. Для установки только NGINX оставьте `vpnctl_install_xray: false` (по умолчанию).
5. Для Xray явно укажите `vpnctl_install_xray: true`, проверенный URL официального ZIP-релиза `xray_release_url`, проверенную SHA-256 сумму `xray_release_sha256` (64 шестнадцатеричных символа), а также путь `xray_config_src` к локальному приватному JSON. Секреты и реальный inventory не публикуйте.
6. Выполните `python3 vpnctl.py --lang ru --inventory inventory/local.yml bootstrap --host test_vps --confirm-fresh-vps --apply`, затем введите `APPLY`.

Защитные проверки: необходимы метка на сервере, `vpnctl_fresh_host: true`, отсутствие служб `x-ui.service` и `xray.service`. Версия 0.3 **ещё не настраивает** NGINX Stream, TLS, REALITY, входные/выходные узлы или резервирование. Это только базовая подготовка для дальнейшего тестирования. Xray в экспериментальной версии запускается от root; прежде чем публиковать узел в интернет, требуется отдельная проверка безопасности и интеграционные испытания.
